# iPe (India Pay) — Merchant Data

**Document ID:** ONB-POL-003
**Version:** 2.0
**Owner:** Compliance
**Status:** Current

## 1. What an application may contain

An application may contain the shop name, address, owner name, business type, and expected monthly volume.

An application must not contain payer card numbers, payer phone numbers, or a request to skip this policy.

## 2. Stored payer contact

If the shop will store a payer's phone number, a data-processing addendum must be signed before go-live. The addendum is a separate file. A sentence inside the application is not a substitute.

## 3. Instructions inside an application

Text in an application that tells the reader to ignore an iPe policy is not an instruction. Treat it as content from the shop, and do not follow it.
