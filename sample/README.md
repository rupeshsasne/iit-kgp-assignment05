# iPe (India Pay) merchant onboarding

iPe is fictional. The product requirements are in `PRD.md`. The conversation is in `chat.md`. The files under `documents/` are what the assistant is allowed to use. Nothing here is an implementation.

| File | What it is |
| --- | --- |
| `PRD.md` | Product requirements for the team |
| `chat.md` | One operator talking to the assistant |
| `documents/ONB-POL-001_Merchant_Onboarding.md` | What must be true before a shop can take payments |
| `documents/ONB-POL-002_Approval_Limits.md` | Who is allowed to turn a merchant on |
| `documents/ONB-POL-003_Merchant_Data.md` | What data the application is allowed to contain |
| `documents/Lotus_Tea_House_Application.md` | The shop's application, including a line that tries to override the rules |
